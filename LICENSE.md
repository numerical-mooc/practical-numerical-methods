# Licensing

Practical Numerical Methods uses separate licenses for instructional content and source code.

## Course content: CC BY 4.0

Unless a file or directory says otherwise, original instructional content is licensed under the [Creative Commons Attribution 4.0 International License](LICENSES/CC-BY-4.0.txt). This includes:

- narrative text and mathematical exposition;
- diagrams, original figures, and other teaching media;
- exercises, assignment prompts, and assessment text;
- Markdown and MyST documents; and
- prose and other instructional content in notebook Markdown cells.

When reusing this material, a suitable attribution is:

> *Practical Numerical Methods*, by Lorena A. Barba and contributors, https://github.com/numerical-mooc/practical-numerical-methods, licensed under CC BY 4.0.

## Source code: BSD 3-Clause

Unless a file or directory says otherwise, source code is licensed under the [BSD 3-Clause License](LICENSES/BSD-3-Clause.txt). This includes:

- Python modules and packages;
- tests and scripts;
- executable examples and notebook code cells; and
- code used to build, verify, or publish the course.

## Notebooks and other mixed files

A notebook may contain material under both licenses: its narrative and instructional content is CC BY 4.0, while its code cells are BSD 3-Clause. Reusers should preserve this distinction when copying material from a notebook.

## Exceptions and third-party material

A specific license or attribution notice attached to a file overrides these repository defaults. Third-party material and datasets retain their original licenses and attribution requirements and will be identified where they appear.

The complete license texts are provided in the [LICENSES](LICENSES/) directory. Those texts, rather than this summary, govern use of the material.
